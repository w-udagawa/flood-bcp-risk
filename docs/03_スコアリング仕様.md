## 3. ハザード等級 H（0〜4）

### 3-1. 代表浸水深

各ソースの階級**下限**を代表値とし、内水・洪水・高潮の最大値を `depth_rep` とする。上限は根拠として併記する。下限を使う理由：国土数値情報の階級（0.5〜3.0 m）が広く、上限採用では過大になるため。階級の粗さは確信度で表現する。

### 3-2. 基本等級

| depth_rep | H |
|---|---|
| 全ソース 0（区域外）かつデータあり | 0 |
| 0 < depth_rep < 0.5 | 1 |
| 0.5 ≤ depth_rep < 1.0 | 2 |
| 1.0 ≤ depth_rep < 3.0 | 3 |
| ≥ 3.0 | 4 |

内水・洪水ともデータが null（未整備）なら H は算出不能 → 建物 status = `insufficient_data`、ただし実績フラグや窪地フラグがあれば H = 2 の暫定値で評価を続け、確信度を下げる。

### 3-3. 補正（合計で最大 +1、上限 4）

| 条件 | 補正 |
|---|---|
| flood_history_flag = true | +1 |
| depression_flag = true または rel_elev_m ≤ −0.3 | +1 |
| landform_class が 谷底低地・旧河道・後背湿地・湿地 のいずれか | +1 |

補正は重複しても +1 まで。H = 0 で実績のみある場合は H = 2 とする（実績は想定より強い証拠）。

## 4. 流入脆弱性等級 V（0〜4）Tier 0

### 4-1. 基礎点（地下階数）

| storeys_below | 基礎 V | 備考 |
|---|---|---|
| 0 | 0 | |
| 1 | 2 | |
| ≥ 2 | 3 | |
| null（不明） | 用途・規模から推定 | commercial_large / station / hospital / office（延床 ≥ 10,000）/ residential_large → 2（推定あり）。それ以外 → 1。確信度を下げ、不足情報に「地下階の有無」を追加 |

### 4-2. 加減点（上限 4、下限 0）

| 条件 | 補正 | 理由 |
|---|---|---|
| total_floor_area_m2 ≥ 3,000 または storeys_above ≥ 6 | +1 | 高圧受変電設備を建物内に持つ可能性が高い（電気設備浸水対策ガイドラインの対象） |
| rel_elev_m ≤ −0.3 | +1 | 道路面より低く、流入しやすい |
| year_built ≥ 2021 | −1 | 電気設備浸水対策ガイドライン（2020 年 6 月）以後の設計。弱い指標 |
| usage_class = station | +1 | 地下ホーム・地下出入口を持つ確率が高い |

### 4-3. Tier 1 上書き（第 6 章の回答による）

Tier 1 の回答がある場合、Tier 0 の V を次の規則で置換または補正する。

| 回答 | 処理 |
|---|---|
| Q3 受変電設備が地下または想定浸水深以下 = はい | V = 4（固定） |
| Q3 = いいえ かつ Q4 非常用発電が想定浸水深より上 = はい かつ Q5 中央監視が地下・低層 = いいえ | V = min(V, 1) |
| Q1 地下階あり = いいえ | 基礎 V = 0 で再計算 |
| Q2 地下出入口あり = はい | +1 |
| Q7 止水板・防水扉あり = はい かつ Q9 止水高さが想定浸水深以上 = はい かつ Q8 設置体制あり = はい | −2 |
| Q7 = はい だが Q8 または Q9 が いいえ/不明 | −1 |
| Q6 排水ポンプが停電時も作動 = はい | −1 |
| Q10 単一系統で全館停止 = はい | +1（V 上限 4） |
| Q11 仮設電源接続口あり = はい | V は変えず、復旧難易度フラグを下げる（I 側 −0 だが対策候補と不足情報から除外） |

## 5. 事業影響度等級 I（0〜4）

### 5-1. 基礎点（用途）

| usage_class | 基礎 I |
|---|---|
| hospital, datacenter, public_critical | 4 |
| station（station_ridership ≥ 50,000） | 4 |
| station（その他）、commercial_large、welfare、logistics（延床 ≥ 10,000） | 3 |
| office（延床 ≥ 10,000）、commercial、school、residential_large、logistics | 2 |
| office、other | 1 |

### 5-2. 加点（上限 4）

| 条件 | 補正 |
|---|---|
| alt_facility_dist_m ≥ 1,000（同用途の代替施設が 1 km 以内にない） | +1 |
| Tier 1 Q12 過去に浸水・停電・長期休業あり = はい | +1 |
| Tier 1 Q10 単一系統で全館停止 = はい | +1 |

## 6. 簡易診断（Tier 1）12 問

回答は「はい / いいえ / 不明」。不明は Tier 0 の値を維持し、確信度に加点しない。

| # | 質問 | 影響先 |
|---|---|---|
| Q1 | 地下階はありますか | V 基礎 |
| Q2 | 地下駐車場・地下出入口・地下街接続・搬入口スロープはありますか | V |
| Q3 | 受変電設備（キュービクル・電気室）は地下、または想定浸水深以下の階にありますか | V（決定的） |
| Q4 | 非常用発電設備と燃料設備は想定浸水深より上にありますか | V |
| Q5 | 中央監視設備・主要制御盤は地下または 1 階にありますか | V |
| Q6 | 排水ポンプは停電時も作動しますか（非常電源接続） | V |
| Q7 | 止水板・防水扉・防水シャッターはありますか | V |
| Q8 | 止水設備の設置担当者と設置判断基準は決まっていますか | V |
| Q9 | 地下開口部ごとの止水高さは想定浸水深を上回りますか | V |
| Q10 | 重要設備が一系統のみで、故障時に全館停止する構成ですか | V, I |
| Q11 | 仮設電源接続口はありますか | 不足情報・対策候補 |
| Q12 | 過去に浸水、漏水、停電、長期休業がありましたか | I, H（実績フラグ true） |

## 7. データ確信度 C（0〜100）

各項目の重みを合計し、存在する項目の重み合計を 100 で正規化した割合。

| 項目 | 重み | 存在条件 |
|---|---|---|
| 内水データ（inland_depth が null でない） | 20 | |
| 洪水データ | 10 | |
| DEM 相対標高（rel_elev_m） | 10 | |
| 地下階数（storeys_below） | 20 | |
| 延床面積または階数 | 10 | |
| 用途（usage_class ≠ other） | 10 | |
| Tier 1 回答（Q1〜Q10 のうち「不明」以外が 7 問以上） | 20 | |

減点：内水ソースの階級幅が 2.5 m 以上（国土数値情報の 0.5〜3.0 m 等）の場合 −10。ハザードデータの公表年が 10 年超なら −10。下限 0。

## 8. 設備被災可能性 P（0〜4）：H × V マトリクス

行 = H、列 = V。

| H \ V | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 0 | 0 |
| 1 | 0 | 1 | 2 | 3 | 3 |
| 2 | 1 | 2 | 3 | 4 | 4 |
| 3 | 2 | 3 | 3 | 4 | 4 |
| 4 | 2 | 3 | 4 | 4 | 4 |

根拠：H1（0.5 m 未満）でも地下開口部があれば設備空間に到達する（自由が丘事例は短時間の局地豪雨による内水）。H が高くても地下がなく設備が上階にあれば P は上がりにくい。

## 9. 対応優先度：P × I マトリクス

行 = P、列 = I。

| P \ I | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 0 | D | D | D | C | C |
| 1 | D | D | C | C | B |
| 2 | D | C | C | B | B |
| 3 | C | C | B | A | A |
| 4 | C | B | A | A | A |

| 優先度 | 意味 | 推奨行動 |
|---|---|---|
| A | 優先現地調査 | Tier 1 回答と現地調査を直ちに実施 |
| B | 簡易診断推奨 | Tier 1 回答を依頼 |
| C | 定期確認 | 次回データ更新時に再評価 |
| D | 現状対応不要 | 記録のみ |

確信度ルール：C < 50 かつ P ≥ 2 の場合、優先度を 1 段階引き上げ（D→C, C→B, B→A）、表記に `*` を付す（例：`B*`）。

## 10. 評価ステータス

| status | 条件 |
|---|---|
| assessed | 正常に評価 |
| insufficient_data | 内水・洪水とも null で、実績・窪地フラグもない |
| out_of_scope | usage_class = residential、または other で延床 < 3,000 |

## 12. 不足情報と優先確認事項の生成規則

| 条件 | 不足情報 | 優先確認事項 |
|---|---|---|
| storeys_below null | 地下階の有無 | 地下階の有無・用途 |
| V ≥ 2 かつ Tier 1 なし | 受変電設備の設置階、非常用発電の設置階、中央監視の位置 | 受変電設備の設置階 |
| Q2 = はい または V ≥ 2 | 地下出入口の止水設備・止水高さ | 地下出入口の止水高さ |
| Q6 不明 | 排水ポンプの非常電源 | 排水ポンプの非常電源 |
| Q10 不明 かつ I ≥ 3 | 系統構成（単一系統か） | 全館停止波及の有無 |

## 13. 対策候補（措置メニュー）

要因から対策 ID を引く。定義は `config/measures.json`。

| ID | 対策 | 提示条件 |
|---|---|---|
| M-01 | 地下・低層の重要設備の設置階確認（図面確認・現地調査） | V ≥ 2 かつ Tier 1 なし |
| M-02 | 受変電設備・非常用発電・中央監視の上階移設または架台かさ上げ・防水区画化 | Q3 = はい または Q5 = はい |
| M-03 | 地下出入口・スロープ・ドライエリア・換気口への止水板・防水扉（JIS A 4716）設置 | Q2 = はい または (V ≥ 2 かつ H ≥ 1) |
| M-04 | 止水設備の設置手順・担当・判断基準の整備、豪雨前訓練 | Q7 = はい かつ (Q8 = いいえ/不明) |
| M-05 | 排水ポンプの非常電源接続・逆流防止 | Q6 = いいえ/不明 かつ V ≥ 2 |
| M-06 | 仮設電源接続口の整備、系統分離・冗長化 | Q10 = はい または Q11 = いいえ |
| M-07 | 浸水検知センサー・雨量水位監視と通知閾値の設定 | P ≥ 2 |
| M-08 | 可搬式止水（プラバリア等）による流入方向制御の検討 | H ≥ 1 かつ (depression_flag または rel_elev_m ≤ −0.3) |
| M-09 | 敷地内雨水貯留・雨庭・バイオスウェル・透水性舗装の導入可能性調査 | H ≥ 1 かつ footprint_area_m2 ≥ 1,000 |
| M-10 | BCP 見直し（代替拠点、復旧時間目標、交換部品の調達計画） | I ≥ 3 かつ P ≥ 2 |
| M-11 | ケーブル・配管貫通部の止水確認 | Q3 = はい または V ≥ 3 |
