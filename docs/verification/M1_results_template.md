# M1 検証結果記入テンプレート

`docs/07_M1検証手順書.md` の手順に沿って V-01〜V-12 を実施した結果をここに
記入する。1 項目 1 表。判定は手順書に記載した基準に沿って記入し、基準が
未確定の項目（手順書末尾「付記」参照）は結果を記入した上で Fable に判断を
仰ぐこと。
